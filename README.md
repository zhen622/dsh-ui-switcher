# DSH UI Switcher

Automatic discovery and mutually-exclusive switching of DeepSeek Harness Web UI/theme plugins, with an Original DSH safety fallback and local display-name aliases.

See [README.zh-CN.md](README.zh-CN.md) for installation, usage, and current DSH rc.7 limitations.

## Development

```bash
npm install
npm run build
npm test
```
